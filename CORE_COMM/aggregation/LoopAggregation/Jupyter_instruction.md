# Instructions to run the Jupyter notebook with the usage example of Loop Aggregation

```
docker login registry.gitlab.com
docker pull registry.gitlab.com/alex-gauvain/hydromodpy/loopaggregation_jupyter
docker run -p 8888:8888 registry.gitlab.com/alex-gauvain/hydromodpy/loopaggregation_jupyter
```

Then open the url that is given in the command window. It should be in the following format:
http://127.0.0.1:8888/?token=...
