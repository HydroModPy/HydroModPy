# Gallery cases that are behind the sources they declare.
#
# Every case records the digest of each file it was published from. When one of
# those files moves on and the case is not republished, the page keeps serving
# the old numbers and nothing says so. `--check` would catch it, but `--check`
# regenerates, so it needs the solver binaries, the data bundles and the run
# that wrote the manifest -- which is why docs-gallery-check.yml verifies four
# of the nine categories. Comparing digests needs none of that, so this check
# covers all nine.
#
# One line per case, because a case is republished as a whole. Republishing
# refreshes its digests, the line stops applying, and this check fails until the
# line is removed: the list only shrinks.
#
# The cost of that granularity, stated so nobody discovers it the hard way: a
# case already on this list can fall further behind without any diff here. The
# line says the case is stale, never by how much. Run
# `python tools/check_docs_inventory.py` with the list emptied to see the
# per-source detail.
