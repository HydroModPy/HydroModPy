# Références méthodes numériques

Ce dossier stocke les articles et notes utilisés comme références
techniques pour les formulations de solveurs et les méthodes numériques.

Références actuelles :

- `Marcais_2017_dynamic_coupling_subsurface_and_seepage_flows.pdf` :
  couplage dynamique entre écoulement souterrain et drainage de surface,
  résolu via une formulation de partition régularisée.
- [`../boussinesq_petsc_vs_marcais_2017.md`](../boussinesq_petsc_vs_marcais_2017.md) :
  comparaison détaillée entre le backend PETSc Boussinesq courant
  d'HydroModPy et Marcais et al. (2017), focalisée sur l'interaction
  de surface.
