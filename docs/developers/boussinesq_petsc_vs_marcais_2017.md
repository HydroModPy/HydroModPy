# PETSc Boussinesq vs Marcais 2017

## Scope

This note compares the current HydroModPy PETSc backend for the Boussinesq solver with:

- `docs/developers/numerical_methods_references/Marcais_2017_dynamic_coupling_subsurface_and_seepage_flows.pdf`
- the current implementation in:
  - `hydromodpy/solver/boussinesq/petsc_runtime.py`
  - `hydromodpy/solver/boussinesq/assembly.py`

The focus is the treatment of the interaction between groundwater and the land surface, especially the onset of seepage and saturation-excess outflow.

## Executive View

The article and the current PETSc backend target the same physical transition:

- below saturation, flow remains subsurface,
- once the water table reaches the surface, excess water must leave through a surface flux.

However, the numerical closures are different.

Marcais et al. (2017) use a regularized partition law:

- the positive incoming balance is partitioned between storage and surface outflow,
- activation is controlled by a smooth saturation indicator `G_r(S / S_c)`,
- the resulting semi-discrete system is treated as an ODE and integrated with a variable-step BDF solver.

The current HydroModPy PETSc backend uses a mixed complementarity formulation:

- `h` is the differential unknown,
- `q_ex` is an algebraic unknown,
- the surface interaction is enforced through `0 <= q_ex perp z_top - h >= 0`,
- the coupled nonlinear system is solved with PETSc SNES at each backward-Euler step.

So the current PETSc method is not the Marcais 2017 method ported to PETSc. It is a different surface closure, more in the spirit of an obstacle or seepage-face complementarity formulation.

## 1. Marcais 2017 Surface Interaction Model

In the article, the primary subsurface state is the storage `S(x,t)`, with a maximum storage `S_c(x)` corresponding to a fully saturated soil column. The subsurface discharge is `Q(x,t)`, and the surface outflow is `q_S(x,t)`.

The regularized partition formulation can be summarized as:

```math
\partial_t S + q_S = -\partial_x Q + N w
```

```math
q_S = G_r(S/S_c)\,R(-\partial_x Q + N w)
```

with:

- `R(u) = max(u, 0)`,
- `G_r(u) = exp(-(1-u)/r)`,
- `0 <= S <= S_c`.

Interpretation:

- the local incoming balance is `-\partial_x Q + N w`,
- if this balance is negative, `R(...) = 0` and no surface outflow is produced,
- if this balance is positive and the soil is close to saturation, `G_r(S/S_c)` activates the surface flux,
- when `S / S_c` approaches `1`, the method transitions smoothly toward the fully saturated regime.

This is a partition law because the positive incoming balance is split into:

- storage increase `\partial_t S`,
- saturation-excess outflow `q_S`.

Two physical contributions are embedded in `q_S`:

- seepage generated by lateral subsurface convergence,
- direct precipitation onto already saturated areas.

That decomposition is explicit in the article because `q_S` is driven directly by `-\partial_x Q + N w`.

## 2. Current PETSc Surface Interaction Model

The current PETSc backend works with the pair `(h, q_ex)` on the cell mesh:

- `h`: hydraulic head,
- `q_ex`: cellwise saturation-excess or exfiltration rate.

The flow balance is assembled in `assembly.py`, and PETSc solves the mixed nonlinear system in `petsc_runtime.py`.

In transient form, the current solve is:

```math
A_i C_i \frac{h_i^{n+1} - h_i^n}{\Delta t}
+ R_i^{lat}(h^{n+1})
+ R_i^{bc}(h^{n+1})
+ q_{drn,i}(h^{n+1})
+ A_i q_{ex,i}^{n+1}
- A_i r_i^{n+1}
- Q_{well,i}^{n+1}
= 0
```

In steady form, the storage term is removed.

The surface interaction is not defined by a constitutive partition law. Instead, it is defined by the complementarity condition:

```math
0 <= q_{ex,i} \perp z_{top,i} - h_i >= 0
```

which means:

- if `h_i < z_top,i`, then `q_ex,i = 0`,
- if `q_ex,i > 0`, then `h_i = z_top,i`.

Numerically, this is enforced through a Fischer-Burmeister residual:

```math
\phi(a,b) = \sqrt{a^2 + b^2} - a - b
```

with scaled variables:

```math
a = q_{ex} / q_scale
```

```math
b = (z_top - h) / h_scale
```

and PETSc SNES solves the coupled system:

```math
F(h, q_ex) = 0
```

The surface flux is therefore whatever value is required to satisfy both:

- the groundwater mass balance,
- the unilateral surface constraint.

## 3. Core Mathematical Difference

The main difference is where the constitutive decision is made.

In Marcais 2017:

- `q_S` is prescribed by a local law of the form `G_r(theta) R(balance)`,
- surface activation is a regularized constitutive partition of the positive balance,
- the method stays in one smoothened regime without introducing `q_S` as an independent algebraic unknown.

In the current PETSc backend:

- `q_ex` is not prescribed by a local constitutive law of `balance`,
- `q_ex` is solved as an unknown together with `h`,
- the surface flux appears as a Lagrange-multiplier-like reaction enforcing `h <= z_top`.

This distinction matters because it changes both the physics represented and the numerical problem class.

## 4. Detailed Comparison for Surface Interaction

### 4.1 Activation Criterion

Marcais 2017:

- activation depends on both saturation and positive local incoming balance,
- no positive balance means no `q_S`,
- the transition is smoothened by `G_r`.

Current PETSc backend:

- activation depends on the surface constraint,
- `q_ex` becomes positive only when needed to keep `h` from exceeding `z_top`,
- there is no explicit regularized pre-activation based on a saturation ratio.

Consequence:

- Marcais allows a small anticipatory activation near saturation when `r > 0`,
- PETSc complementarity does not anticipate; it reacts exactly at the active constraint.

### 4.2 What Drives Surface Outflow

Marcais 2017:

- `q_S` is driven by `R(-\partial_x Q + N w)`,
- only the positive incoming flux can feed the surface outflow,
- the article is explicit that `q_S` contains seepage plus direct rain on saturated areas.

Current PETSc backend:

- `q_ex` is whatever residual outflow is needed once the head constraint is active,
- it is not tied only to recharge,
- any mechanism that would otherwise push `h` above the surface can be offset by `q_ex`.

Consequence:

- the PETSc closure is more general as a constraint enforcement device,
- but it is less specific than the article with respect to the physical decomposition of surface contributions.

### 4.3 Role of Recharge on Saturated Areas

Marcais 2017:

- direct precipitation on saturated areas is explicitly part of `q_S`,
- this is built directly into the partition formula through `N w`.

Current PETSc backend:

- recharge remains a source in the groundwater balance,
- if the cell is capped at `z_top`, the solve may produce a compensating `q_ex`,
- but the decomposition "direct rainfall on saturated area" versus "return flow from below" is not explicit.

Consequence:

- the resulting flux can be comparable in value,
- but the interpretation is different: explicit partitioned surface production in the article versus algebraic balance reaction in the PETSc backend.

### 4.4 Negative Balance and Desaturation

Marcais 2017:

- `R(balance)` cancels surface outflow as soon as the balance becomes negative,
- the saturated zone can desaturate through the storage equation.

Current PETSc backend:

- when the solution falls below `z_top`, complementarity forces `q_ex = 0`,
- desaturation is handled naturally by the groundwater balance with inactive constraint.

Here the two approaches are qualitatively similar:

- no surface outflow in the desaturating regime,
- return to a purely subsurface dynamics when the cap is inactive.

The difference remains in the triggering mechanism:

- explicit ramp on the balance in Marcais,
- active or inactive inequality constraint in PETSc.

### 4.5 Smooth Regularization vs Exact Constraint

Marcais 2017:

- uses `G_r`,
- the parameter `r` controls the width and stiffness of the transition layer,
- the transition is intentionally regularized.

Current PETSc backend:

- the surface closure is exact at the level of the complementarity zero set,
- the Fischer-Burmeister residual has the exact complementarity solution set,
- the tiny denominator floor is only for Jacobian stability near `(q_ex, z_top - h) = (0, 0)`.

Consequence:

- Marcais trades exactness of the surface cap for a smoother ODE solve,
- PETSc trades smoothness for a sharper physical constraint.

### 4.6 Problem Class Seen by the Time Integrator

Marcais 2017:

- after regularization and space discretization, the system is treated as an ODE,
- time integration is done with MATLAB `ode15s`, variable-step and variable-order BDF.

Current PETSc backend:

- each HydroModPy step is one backward-Euler nonlinear solve,
- the unknown vector contains both differential and algebraic components,
- this is a mixed DAE-like nonlinear system solved by SNES, not by PETSc TS.

Consequence:

- the article method is closer to "regularized stiff ODE",
- the current PETSc method is closer to "semi-explicit DAE with complementarity closure".

## 5. Relation to the Historical HydroModPy Smooth Law

There is an important architectural point.

The article is much closer to the historical HydroModPy smooth saturation-excess law than to the current PETSc complementarity backend.

The existing smooth assembly law is:

```math
q_{ex} = \exp(-(1-\theta)/r)\,\max(balance, 0)
```

with:

- `theta = clip((h - z_bottom) / (z_top - z_bottom), 0, 1)`,
- `balance = - lateral_residual / area + positive_surface_input`.

This is structurally very close to Marcais 2017:

- same saturation-controlled regularization,
- same ramp on a positive incoming balance,
- same interpretation as a partitioned surface release when the subsurface system keeps filling near saturation.

So:

- Marcais 2017 is conceptually aligned with the HydroModPy smooth V1 path,
- the PETSc backend is conceptually aligned with the DAE/complementarity V2 path.

## 6. Practical Consequences for Model Behaviour

If the objective is:

- strict enforcement of `h <= z_top`,
- clear active or inactive saturated surface constraint,
- compatibility with nonlinear complementarity tooling,

then the current PETSc formulation is coherent.

If the objective is:

- fidelity to Marcais 2017,
- explicit partition between storage increase and surface outflow,
- direct representation of precipitation on already saturated cells inside the closure,

then the current PETSc formulation is not the right match.

In particular, the current PETSc backend:

- does not reproduce the article's regularized partition law,
- does not make `q_ex` a direct function of `R(-div Q + surface_input)`,
- does not use the article's ODE plus BDF integration strategy.

## 7. Recommended Next Step if We Want Closer Fidelity to the Article

If the goal is to match Marcais 2017 more closely while staying in PETSc, the clean option is to introduce a separate surface interaction mode, for example:

- `surface_interaction = "regularized_partition"`
- `surface_interaction = "complementarity"`

Then:

- the current PETSc backend can remain the complementarity path,
- a new PETSc path can keep the unknown `h` only and use the regularized partition closure from the article,
- or a mixed PETSc path can keep `(h, q_ex)` but constrain `q_ex` with the article law instead of a pure complementarity relation.

The first option is the most faithful:

- keep Marcais-like `q_ex = G_r(theta) R(balance)`,
- solve the resulting stiff ODE with PETSc TS/BDF or continue with implicit one-step solves,
- retain the complementarity backend as a distinct numerical method rather than merging the two ideas.

## Bottom Line

For the surface interaction, Marcais 2017 and the current PETSc backend are similar in intent but different in formulation.

Marcais 2017:

- regularized partition of the positive incoming balance,
- smooth activation through saturation ratio,
- ODE viewpoint.

Current PETSc backend:

- mixed `(h, q_ex)` solve,
- exact surface cap through complementarity,
- DAE-like viewpoint.

The article is therefore a strong reference for the historical smooth HydroModPy saturation-excess law, but only a partial reference for the PETSc complementarity backend.
