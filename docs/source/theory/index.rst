Theory
======

This section groups method-focused notes that explain the scientific models
implemented in HydroModPy.

It is the right place for:

- mathematical formulations,
- project-level physical scope and modelling assumptions,
- hydrological and recharge-generation chains,
- modelling assumptions and simplifications,
- solver-specific theory notes,
- inverse-problem and calibration notes.

Workflow orchestration, entry points, and user-facing run families are
documented elsewhere:

- :doc:`../seven-modes` explains how HydroModPy is driven;
- :doc:`../getting_started/workflow-families` explains which workflows exist;
- this section explains the theoretical content those workflows rely on.
