Bibliography
============

References cited in the HydroModPy documentation. Only cited entries are listed.

The list is generated from ``docs/source/theory/references.bib`` by the
``sphinxcontrib-bibtex`` extension. To add a reference, append a BibTeX entry to
that file and cite it with ``:cite:`<key>``` from any documentation page. An
entry that no page cites does not appear here.
