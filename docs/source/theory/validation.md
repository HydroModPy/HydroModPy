# Validation

Every check below is a test of `tests/validation/`, run in continuous
integration. Each one compares a computation with a reference that does not come
from HydroModPy: a closed-form solution, a published MODFLOW 6 example, a
manufactured solution, or a parameter that a calibration must find again.
Open a row to read what it compares, the solvers it runs and the thresholds it
must stay under.
