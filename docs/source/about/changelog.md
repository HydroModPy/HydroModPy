# Changelog

Every release of HydroModPy and every change since the last one, newest first. The page is the
`CHANGELOG.md` file at the root of the repository, included as it is. It follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning](https://semver.org/). Under each release, *Added* lists new features,
*Changed* lists changes of behaviour, *Removed* lists what was deleted and *Fixed* lists bug
fixes.

The `[Unreleased]` section is the work merged since the last release. It ships with the next
version.

The keys added, removed or changed in the TOML file between two versions are listed, from the
models, in {doc}`What changed in the TOML </reference/changes>`. For what a version number
promises, see {doc}`Versions and stability <versions>`.
