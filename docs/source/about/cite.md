# Cite

If HydroModPy supports your work, cite the technical note. If you also cite the software,
give the version you ran: `hmp --version` prints it with the Git commit.

The note is the preferred citation of the project. It is a preprint on EGUsphere,
[doi:10.5194/egusphere-2026-868](https://doi.org/10.5194/egusphere-2026-868). The software has
no DOI of its own. The entries below are written from `CITATION.cff` at the root of the
repository, the file GitHub reads behind "Cite this repository". They are for version
{{ release }}, the version this site documents.

When you cite a result, add the solver that computed it (MODFLOW 6, MODFLOW-NWT or the
Boussinesq solver) and the version of its executable.

## BibTeX

```{hmp-citation} bibtex
```

## RIS

```{hmp-citation} ris
```

## Plain text

```{hmp-citation} text
```
