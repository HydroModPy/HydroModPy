# Cite

If HydroModPy supports your work, cite the technical note. If you also cite the software,
give the version you ran: `hmp --version` prints it with the Git commit.

The note is the preferred citation of the project. It is published in *Hydrology and Earth
System Sciences* (2026, volume 30, pages 5571 to 5592),
[doi:10.5194/hess-30-5571-2026](https://doi.org/10.5194/hess-30-5571-2026). It describes
version 1.0 of the toolbox. The software has no DOI of its own. The entries below are written
from `CITATION.cff` at the root of the repository, the file GitHub reads behind "Cite this
repository". The software entry is for version {{ release }}, the version this site documents.

When you cite a result, add the solver that computed it (MODFLOW 6, MODFLOW-NWT or the
Boussinesq solver) and the version of its executable.

## BibTeX

```{hmp-citation} bibtex
```

## RIS

```{hmp-citation} ris
```

## Plain text

```{hmp-citation} text
```

## Authors and affiliations

The order and the affiliations are those of the published note.

