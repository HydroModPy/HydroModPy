# Cite

If HydroModPy supports your work, cite the technical note. If you also cite the software,
give the version you ran: `hmp --version` prints it with the Git commit.

The note is the preferred citation of the project. It is published in *Hydrology and Earth
System Sciences* (2026, volume 30, pages 5571 to 5592),
[doi:10.5194/hess-30-5571-2026](https://doi.org/10.5194/hess-30-5571-2026). It describes
version 1.0 of the toolbox.

The software is archived on Zenodo. Its concept DOI,
[doi:10.5281/zenodo.22141925](https://doi.org/10.5281/zenodo.22141925), names every version
and resolves to the latest archive. Each archived version also has a DOI of its own, listed on
that page. A version not archived yet, such as a pre-release, is cited with the concept DOI.

The entries below are written from `CITATION.cff` at the root of the repository, the file
GitHub reads behind "Cite this repository". The software entry is for version {{ release }},
the version this site documents, with its DOI when Zenodo has archived it.

When you cite a result, add the solver that computed it (MODFLOW 6, MODFLOW-NWT or the
Boussinesq solver) and the version of its executable.

## BibTeX

```{hmp-citation} bibtex
```

## RIS

```{hmp-citation} ris
```

## Plain text

```{hmp-citation} text
```
