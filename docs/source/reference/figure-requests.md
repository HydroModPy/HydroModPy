# Figure requests

Every table on this page is read from the code of the figure path when the site is built. To draw one, see {doc}`../contribute/architecture/how-to/add-a-figure`.

## Fields

A figure is a request, and a request holds panels.

```{hmp-figure-requests} fields
```

## Frames

A panel is drawn by one frame.

```{hmp-figure-requests} frames
```

## Closed values

These words are the only ones a request accepts for the fields they fill.

```{hmp-figure-requests} vocabularies
```

## Quantities

A variable names a quantity, and the quantity decides how it is shown.

```{hmp-figure-requests} quantities
```

## Variables

A panel names variables of these registries.

```{hmp-figure-requests} variables
```

## Presets

A preset is a request that lists the fields a user may fill.

```{hmp-figure-requests} presets
```

## Special figures

A special figure is a preset drawn by a function, and it takes no panel.

```{hmp-figure-requests} specials
```

## Overlays

An overlay is a context layer on a map or a section.

```{hmp-figure-requests} overlays
```
