# Figures

Every figure HydroModPy can draw, read from the figure registry of the code: what it
reads, when it can be drawn, the options it takes with their type and default, and the class
that draws it. Open a figure for its card. A preview image shows beside the name when one has
been rendered for it.

To write a new figure, see {doc}`../contribute/architecture/how-to/add-a-figure`.
