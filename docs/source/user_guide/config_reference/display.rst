Starter TOML snippet
--------------------

.. dropdown:: Click to expand a copy-pasteable ``[display]`` TOML skeleton
   :icon: code
   :animate: fade-in-slide-down

   Copy this block into your ``project.toml`` and uncomment the lines
   you want to set. Sub-tables (``[parent.subfield]``) appear in the
   order Pydantic expects them.

   .. code-block:: toml

      [display]
      # enabled = true
      # preset = "default"
      # show = false
      # save = true
      # output_dir = "figures"
      # cmap = "viridis"
      # figures = ...  # uses factory default

      [display.flow]
      # enabled = true
      # cross_section = true
      # streamflow = true
      # piezometry = true
      # watertable_map = true
      # dem_map = true
      # budget = false
      # hydrography = true
      # boussinesq_state = true
      # boussinesq_diagnostics = true
      # boussinesq_mass_balance = true
      # boussinesq_probes = true
      # boussinesq_edge_flux = true

      [display.particles]
      # enabled = true
      # pathlines = false

      [display.transport]
      # enabled = true
      # concentration = false
      # gif = false
      # web_animation = false
