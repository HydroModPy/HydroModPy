[observation] ObservationConfig
===============================

TOML section: ``[observation]``

Pydantic model: ``ObservationConfig`` defined in ``hydromodpy.simulation.planning.observation_config``.

`Source on GitHub <https://github.com/HydroModPy/HydroModPy/blob/main/hydromodpy/simulation/planning/observation_config.py#L67>`__

Configuration for ``[observation]``: points sampled during the run.

Example
-------
.. code-block:: toml

    [observation]
    variables = ["head", "watertable_depth"]

    [[observation.points]]
    id = "piezo_amont"
    x = 395100.0
    y = 6824925.0
    depth = 12.5
