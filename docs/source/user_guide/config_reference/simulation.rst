Starter TOML snippet
--------------------

.. dropdown:: Click to expand a copy-pasteable ``[simulation]`` TOML skeleton
   :icon: code
   :animate: fade-in-slide-down

   Copy this block into your ``project.toml`` and uncomment the lines
   you want to set. Sub-tables (``[parent.subfield]``) appear in the
   order Pydantic expects them.

   .. code-block:: toml

      [simulation]
      # name = ""
      # tags = ...  # uses factory default
      # if_exists = "version"

      # contact_email = ...  # default = None

      # study_area_name = ...  # default = None
      # outlet_x = ...  # default = None
      # outlet_y = ...  # default = None
