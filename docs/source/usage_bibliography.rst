Papers using HydroModPy
=======================

Curated list of peer-reviewed publications and pre-prints that built on
HydroModPy, in reverse chronological order. The list seeds an ongoing
"papers using HydroModPy" registry maintained semi-automatically via
Google Scholar alerts and Zenodo notifications.

If a publication of yours is missing, send a pull request that adds the
BibTeX entry to ``docs/source/theory/references.bib`` and a one-line
summary below. Cite the paper here using the ``:cite:`` role so the
listing stays in sync with the bibliography.

How HydroModPy was used in each paper
-------------------------------------

- :cite:`abherve2025climate` Coupled climate-change scenarios on a
  compartmentalized basement aquifer, with calibration of groundwater
  seepage against the active stream network derived from HydroModPy.
- :cite:`abherve2024headwater` Calibration of groundwater flow models
  using headwater streamflow intermittence, building on the active
  stream network metric exposed by HydroModPy.
- :cite:`abherve2023` Initial demonstration of the
  seepage-network-based calibration that became one of HydroModPy's
  signature workflows.
- :cite:`floriancic2024knickpoint` Independent application to a
  Swiss mountain stream knickpoint, run with the in-house Boussinesq
  backend.
- :cite:`lemesnil2024coastal` Coastal aquifer heterogeneity from a
  single piezometer chronicle; HydroModPy is used as the forward model
  inside the inverse loop.
- :cite:`marti2024wetland` Wetland sensitivity to recharge changes,
  with catchment-scale runs orchestrated through the simulation
  workflow.

Companion papers and software citation
