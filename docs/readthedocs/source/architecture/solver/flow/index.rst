Flow Solver Architecture
========================

This section groups solver-architecture pages for the ``flow`` process.

The hierarchy is:

1. process: ``flow``,
2. solver type or family: MODFLOW family or Boussinesq family,
3. inside MODFLOW: shared lifecycle, MODFLOW 6 stack, MODFLOW-NWT stack, and
   transport coupling.
