Steady synthetic groundwater-flow case used to validate one sloping-topography setup with distributed top drainage under the linearized unconfined model.

- aquifer thickness: `30.0 m`,

- simulated observable: `watertable_elevation`.
- Available solver variants: MODFLOW-NWT, MODFLOW 6.

What It Shows
-------------

- Sloping-topography drainage behavior without introducing a free seepage-face problem
- Primary metrics: head-profile RMSE, max abs error, cross-row spread, minimum clearance above topography.
- Solver-specific figures and metrics are shown side by side so the same benchmark can be read across backends.

Analytical Reference
--------------------

- compared quantity: row-averaged head profile along `x`,
- reference: steady linearized solution of `T h'' - c_a (h - z_top) = 0`,

.. math::

   T_0\,\frac{\mathrm{d}^2u}{\mathrm{d}x^2}-\lambda_d\,u=0,\qquad u=h-z_{\mathrm{top}}(x)

.. math::

   z_{\mathrm{top}}(x)=z_0+A\left(1-\frac{x-x_{\min}}{L}\right),\qquad u(x)=u_w\frac{\sinh\left(\beta(L-x)\right)}{\sinh\left(\beta L\right)}+u_e\frac{\sinh\left(\beta x\right)}{\sinh\left(\beta L\right)}
