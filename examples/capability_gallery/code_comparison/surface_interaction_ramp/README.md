Assets for the recharge-ramp cross-code benchmark.

- `ramp_reference_k.*`: reference conductivity run with the committed six-method benchmark
- `ramp_high_k.*`: high-conductivity run generated from the Linux `MODFLOW 6` vs `PETSc complementarity` benchmark
- `surface_interaction_ramp_configuration.png`: schematic of the synthetic strip configuration used by both tabs

The `High K` source run is produced from Linux with:

`tools/investigate_surface_interaction_highk_linux.py`

Gallery assets are regenerated by:

`tools/doc_gallery/generate_code_comparison_assets.py`
