# Geographic Gallery Source Assets

This folder stores the canonical versioned image inputs for the geographic
capability-gallery pages.

These assets are derived from committed `data-overview` runs, but they live
outside `docs/source/_static/` so the gallery generator can treat
them as stable source material rather than as generated outputs feeding
themselves.

Current subfolders mirror the geographic gallery cases:

- `watershed_overview/`
- `bdtopage_hydrography_overlay/`
- `nancon_identity_card/`
- `nancon_observed_timeseries/`
