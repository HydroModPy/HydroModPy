# Natural Geology/K Boussinesq Comparison

This folder contains the first runnable natural comparison scaffold for the new
Boussinesq validation testbed work.

The current case is still a one-site scaffold, but it is configured as a
refined natural demonstrator rather than the very coarse smoke test:

- one site, `site_01`, taken from the existing `armorican_demo_sites.csv`;
- one shared physical setup with natural DEM, river extraction, geology zones,
  heterogeneous `K` from the current demo geology table, and a 24-month
  seasonal recharge sequence;
- two child simulations generated by `workflow = "comparison"`:
  `mf6_ref` and `bouss_candidate`;
- no pre-existing mesh input. Each child follows the normal simulation path and
  regenerates its catchment mesh through `mesh_catchment`.

The mesh settings are deliberately much finer than the first smoke run:
`global_size = 130 m`, `min_size = 45 m`, `interface_size = 70 m`, and
`threshold_area_km2 = 0.2` for river extraction. The target is to obtain a map
comparison with enough cells to show river and geology effects.

Run the comparison:

```powershell
python -m hydromodpy run `
  examples\projects\10_testbed_workflow\boussinesq\natural_geology_k\compare_site_01_mf6_bouss.toml
```

Then refresh the existing synthesis page for the current site catalogue:

```powershell
python examples\projects\10_testbed_workflow\reporting\generate_testbed_web_report.py `
  examples\projects\10_testbed_workflow\outputs\nwt_small_catchment_flux `
  --site-catalog examples\projects\10_testbed_workflow\site_tables\armorican_demo_sites.csv `
  --comparison-root examples\projects\10_testbed_workflow\outputs\nwt_small_catchment_flux\comparisons\site_01_refined_mf6_vs_bouss `
  --title "Generic NWT flux testbed report"
```

The comparison output is written under:

```text
examples/projects/10_testbed_workflow/outputs/nwt_small_catchment_flux/comparisons/site_01_refined_mf6_vs_bouss/
```

Because the comparison id contains `site_01`, the generic synthesis page can
associate it with `web_synthesis/cases/site_01.html` and embed the key
comparison figures.

Notes:

- `geology_K_dummy_demo.csv` is still a demo hydraulic-conductivity table. It is
  heterogeneous and useful for checking the workflow, but it is not a curated
  scientific K table.
- This is a refined one-site comparison, not the full natural multi-basin
  testbed.
- The `geology_K_dummy_demo.csv` table should still be replaced by a curated K
  table before using this as a scientific natural benchmark.
- Heads and water-table depths are the primary comparable quantities. Native
  drain, seepage, surface-excess and budget terms are diagnostics unless the
  comparison workflow has explicitly aggregated them into
  `comparable_outflow_total_m3_s`.
