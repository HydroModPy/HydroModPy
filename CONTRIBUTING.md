# Contributing to HydroModPy

The contributor guide is at
<https://docs.hydromodpy.fr/main/contribute/index.html>. Start there:

- [Quick start](https://docs.hydromodpy.fr/main/contribute/quick-start.html):
  set up an environment and run a first test.
- [Handbook](https://docs.hydromodpy.fr/main/contribute/handbook.html):
  issues, setup, style, tests, branches and commit rules.
- [Recipes](https://docs.hydromodpy.fr/main/contribute/architecture/how-to/index.html):
  add a config field, a solver, a data source, a figure or a command.
- [CI workflows](https://docs.hydromodpy.fr/main/contribute/project/ci-workflows.html):
  what each check runs and how to read a failure.
- [Cut a release](https://docs.hydromodpy.fr/main/contribute/architecture/how-to/cut-a-release.html).

Report bugs and request features at
<https://github.com/HydroModPy/HydroModPy/issues>.

Commits follow Conventional Commits: one line, at most 72 characters, no body.
Allowed types: `feat`, `fix`, `refactor`, `cleanup`, `perf`, `chore`, `docs`,
`tests`, `validation`, `examples`, `pipeline`, `config`, `adapters`, `data`,
`style`.

By contributing you agree that your contribution will be released under the
[Eclipse Public License 2.0](https://opensource.org/licenses/EPL-2.0).
